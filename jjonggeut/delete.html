쫑긋 데이터 삭제 요청

앱 「쫑긋」(com.jjonggeut.app) · 개발자 개인개(gaeingae) · 2026.11.08

쫑긋은 회원가입과 로그인이 없습니다. 대부분의 정보는 이용자의 휴대폰에만 있어서 직접 바로 지울 수 있고, 서버에 남은 일부 정보는 이메일로 삭제를 요청하실 수 있습니다.

1. 휴대폰에 있는 데이터 지우기 (바로 삭제)

  • 앱에서 설정 > 기록 지우기를 누르면 분석 기록과 연 리포트(대화 상대 이름, 집계 숫자)가 모두 지워집니다.
  • 앱을 삭제하면 휴대폰에 저장된 쫑긋 데이터가 모두 지워집니다.
  • 카카오톡 대화 원문은 처음부터 서버로 보내지 않으므로 서버에 지울 대화 내용이 없습니다.

2. 서버에 있는 데이터 삭제 요청 (이메일)

  1. keundo403@gmail.com 으로 제목 「쫑긋 데이터 삭제 요청」 메일을 보내 주세요.
  2. 본문에 지울 대상을 찾을 수 있는 정보를 적어 주세요.
    • 건의 글: 보낸 날짜와 글 내용 일부
    • 당근 구매·잔액: Google Play 영수증 메일의 주문 번호(GPA.로 시작)
  3. 확인 후 지체 없이(늦어도 10일 안에) 삭제하고 결과를 회신합니다.

3. 삭제되는 데이터와 보관되는 데이터

  • 요청 시 삭제: 건의 글, 앱 오류 기록, 당근 잔액, 처음 선물 지급 기록(되돌릴 수 없게 변환된 기기 값).
  • 자동 삭제: 호출 횟수 확인용 변환 IP는 최대 24시간 뒤, 건의 글과 오류 기록은 최근 2,000건을 넘으면 오래된 것부터 자동 삭제됩니다. 리포트 해설 요청 내용은 처음부터 저장하지 않습니다.
  • 법령에 따라 보관: 결제 기록(구매 일시, 상품, 금액, 주문 번호)은 「전자상거래 등에서의 소비자보호에 관한 법률」에 따라 5년간 보관한 뒤 파기합니다. 카드 정보 등 결제 수단 정보는 Google이 처리하며 개발자는 보관하지 않습니다.

자세한 내용은 쫑긋 개인정보처리방침을 참고해 주세요.
